# Session: 2026-04-21 — ADR-00007 Heading-Boundary Chunking Implementation

## What was done

Implemented the full heading-boundary chunking strategy as specified in ADR-00007 (now Accepted).

### New files
- `src/mcp_project_context_server/indexing/chunker.py` — `chunk_markdown()` function implementing:
  - Split on `##`-level headings only (ADR decision: top-level sections)
  - Heading text preserved as first line of each chunk
  - Intelligent sub-splitting for oversized sections: paragraph boundaries → `###` sub-headings → last-resort passthrough
  - Configurable via `max_chunk_size` parameter
- `tests/test_chunker.py` — 13 unit tests covering all chunking scenarios (empty, no headings, basic sections, oversized sections, content integrity)

### Modified files
- `src/mcp_project_context_server/indexing/chroma/indexer.py`:
  - Replaced fixed 1000-char chunking with `chunk_markdown()` call
  - Added `CHUNK_SIZE` env var (default 1500)
  - Added `importlib.metadata` version read (`_SERVER_VERSION`)
  - `create_collection()` now passes `metadata={"server_version": _SERVER_VERSION}`
  - Chunk document IDs changed to `{source}::chunk::{i}` format (ADR-00008 compliant)
  - Metadata key renamed from `file` to `source` (POSIX path, ADR-00008)
- `src/mcp_project_context_server/tools/load_context.py`:
  - Added `_needs_reindex()` helper: compares collection `server_version` metadata against current runtime version
  - Migration notice prepended to output when version mismatch detected (or `server_version` absent)
  - No notice shown when collection is absent (user hasn't indexed yet)
- `tests/test_tool_index_context.py` — added 2 new integration tests for chunker usage and collection metadata
- `tests/test_tool_load_context.py` — added 6 new tests covering all migration notice scenarios

### Test results
35/35 passing, zero regressions.

## Key decisions made
- All decisions follow ADR-00007 exactly as Accepted.
- `_SERVER_VERSION` is read via `importlib.metadata.version()` at module load time in both `indexer.py` and `load_context.py`.
- Migration detection is graceful: any exception from `get_collection` returns `False` (no noise for un-indexed projects).
