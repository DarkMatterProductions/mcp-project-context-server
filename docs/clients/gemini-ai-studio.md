# Gemini CLI / AI Studio

## Overview

The [Gemini CLI](https://github.com/google-gemini/gemini-cli) is Google's open-source command-line AI tool powered by Gemini models. It supports MCP servers via **STDIO transport**. [Google AI Studio](https://aistudio.google.com) is the web-based counterpart for prototyping; the Gemini CLI is the recommended interface for local MCP server integration.

---

## Prerequisites

- [Gemini CLI](https://github.com/google-gemini/gemini-cli) installed:
  ```bash
  npm install -g @google/gemini-cli
  ```
- Python 3.10+ and `pip`
- A Google API key from [aistudio.google.com/app/apikey](https://aistudio.google.com/app/apikey)

---

## Installation

Install the package with the extra that matches your chosen embedding provider:

```bash
# Google Gemini API (natural pairing with Gemini CLI — same API key)
pip install "mcp-project-context-server[google]"

# Google Vertex AI (GCP-native, uses ADC)
pip install "mcp-project-context-server[google-vertex]"

# Ollama (local, no API key required)
pip install "mcp-project-context-server[ollama]"

# Voyage AI
pip install "mcp-project-context-server[voyage]"

# OpenAI
pip install "mcp-project-context-server[openai]"

# Cohere
pip install "mcp-project-context-server[cohere]"

# PostgreSQL vector store (any embedding provider)
pip install "mcp-project-context-server[pgvector]"

# Everything
pip install "mcp-project-context-server[all]"
```

Verify:

```bash
which project-context-server
```

## Configuration

The Gemini CLI stores MCP server configuration at:

| OS | Path |
|----|------|
| **Linux / macOS** | `~/.gemini/settings.json` |
| **Windows** | `%USERPROFILE%\.gemini\settings.json` |

## Embedding Provider Examples

Each example is a complete `~/.gemini/settings.json`. All use `chroma-local` as the vector store (the default). To use a different vector store, see [Vector Store Configuration](#vector-store-configuration).

---

### Google Gemini API (recommended pairing)

Using `EMBED_PROVIDER=google` means your embeddings are generated by the same Google infrastructure that powers the Gemini models. This avoids cross-provider setup and uses a single API key. The same key is used for both the Gemini CLI (`GEMINI_API_KEY`) and the embedding provider (`GOOGLE_API_KEY`).

Get your API key at [aistudio.google.com/app/apikey](https://aistudio.google.com/app/apikey).

```json
{
  "mcpServers": {
    "project-context": {
      "command": "/usr/local/bin/project-context-server",
      "env": {
        "EMBED_PROVIDER": "google",
        "GOOGLE_API_KEY": "AIzaxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx",
        "GOOGLE_EMBED_MODEL": "text-embedding-004",
        "VECTOR_STORE_PROVIDER": "chroma-local",
        "REPO_PROVIDER": "local"
      }
    }
  }
}
```

### Ollama (local, free)

No API key required. Requires [Ollama](https://ollama.com) running locally.

```bash
ollama pull nomic-embed-text
```

```json
{
  "mcpServers": {
    "project-context": {
      "command": "/usr/local/bin/project-context-server",
      "env": {
        "EMBED_PROVIDER": "ollama",
        "OLLAMA_HOST": "http://localhost:11434",
        "OLLAMA_EMBED_MODEL": "nomic-embed-text",
        "VECTOR_STORE_PROVIDER": "chroma-local",
        "REPO_PROVIDER": "local"
      }
    }
  }
}
```

**Popular Ollama embedding models:**

| Model | Size | Notes |
|-------|------|-------|
| `nomic-embed-text` | ~274 MB | Fast, good general purpose (default) |
| `mxbai-embed-large` | ~669 MB | Higher quality |
| `all-minilm` | ~46 MB | Lightweight |

## Vector Store Configuration

Replace the `VECTOR_STORE_PROVIDER` and related variables in any of the examples above.

---

### ChromaDB Local (default)

No extra infrastructure required. Data persists to `~/.mcp-data/chroma` by default.

```json
"env": {
  "VECTOR_STORE_PROVIDER": "chroma-local",
  "CHROMA_DIR": "/home/yourname/.mcp-data/chroma"
}
```

`CHROMA_DIR` is optional — omit it to use the default path.

---

### ChromaDB HTTP

Connects to a remote or containerized ChromaDB instance.

```json
{
  "mcpServers": {
    "project-context": {
      "command": "/usr/local/bin/project-context-server",
      "env": {
        "EMBED_PROVIDER": "google",
        "GOOGLE_API_KEY": "AIzaxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx",
        "GOOGLE_EMBED_MODEL": "text-embedding-004",
        "VECTOR_STORE_PROVIDER": "chroma-http",
        "CHROMA_HOST": "chroma.example.com",
        "CHROMA_PORT": "8000",
        "CHROMA_API_KEY": "your-chroma-api-key",
        "REPO_PROVIDER": "local"
      }
    }
  }
}
```

`CHROMA_API_KEY` is optional — omit it for unauthenticated instances.

---

### pgvector (PostgreSQL)

For shared or persistent team indexes. Requires `pip install "mcp-project-context-server[pgvector]"` and `CREATE EXTENSION IF NOT EXISTS vector;` on the database.

```json
{
  "mcpServers": {
    "project-context": {
      "command": "/usr/local/bin/project-context-server",
      "env": {
        "EMBED_PROVIDER": "google",
        "GOOGLE_API_KEY": "AIzaxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx",
        "GOOGLE_EMBED_MODEL": "text-embedding-004",
        "VECTOR_STORE_PROVIDER": "pgvector",
        "PGVECTOR_CONNECTION_STRING": "postgresql://mcpuser:password@db.example.com:5432/mcp_context",
        "REPO_PROVIDER": "local"
      }
    }
  }
}
```

## Repository Provider Configuration

---

### Local (default)

No configuration required. Pass the absolute path to your project as `project_path`.

---

### GitHub

```json
"env": {
  "REPO_PROVIDER": "github",
  "REPO_AUTH_TOKEN": "ghp_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx"
}
```

Get a token at [github.com/settings/tokens](https://github.com/settings/tokens) with `repo` scope. For GitHub Enterprise, also add `"REPO_BASE_URL": "https://github.example.com/api/v3"`.

---

### GitLab

```json
"env": {
  "REPO_PROVIDER": "gitlab",
  "REPO_AUTH_TOKEN": "glpat-xxxxxxxxxxxxxxxxxxxx"
}
```

Get a token at **User Settings → Access Tokens** with `read_api` scope. For self-hosted GitLab, also add `"REPO_BASE_URL": "https://gitlab.example.com"`.

---

### Gitea

`REPO_BASE_URL` is required — there is no default.

```json
"env": {
  "REPO_PROVIDER": "gitea",
  "REPO_BASE_URL": "https://gitea.example.com",
  "REPO_AUTH_TOKEN": "xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx"
}
```

## Verification / Quick Test

Start a Gemini CLI session:

```bash
gemini
```

Ask:

```
Index /path/to/my-project and give me a high-level overview of the codebase.
```

The CLI will invoke `index_project_context` via MCP, then answer using the indexed content. On subsequent sessions the index is already populated, so queries run immediately.

**Troubleshooting:**
- Run `gemini --mcp-debug` to see MCP server startup logs
- Confirm `project-context-server` is on your `PATH` and the path in `settings.json` is absolute
- If using `EMBED_PROVIDER=google`, confirm your `GOOGLE_API_KEY` has the **Generative Language API** enabled in your Google Cloud project
